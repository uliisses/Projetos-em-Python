## 📂 Projetos em Destaque

### 🤖 Agente de IA Conversacional com Integração de LLM
`Python` `Streamlit` `OpenAI API`

Chatbot funcional com interface web, integrando um modelo de linguagem de terceiros via API REST (padrão OpenAI) a um front-end em Streamlit. Implementa gerenciamento de estado de sessão para manter o histórico de conversas e tratamento de exceções para falhas de conexão e de resposta da API. Arquitetura pensada para ser facilmente adaptável a diferentes modelos de linguagem, permitindo trocar de provedor sem reescrever a lógica principal.

---

### 📊 Modelo de Machine Learning para Previsão de Score de Crédito
`Python` `Scikit-learn` `Pandas`

Pipeline completo de ciência de dados: pré-processamento, codificação de variáveis categóricas (Label Encoding), separação treino/teste e treinamento de modelos supervisionados. Comparação de desempenho entre dois algoritmos de classificação (Random Forest e KNN), validados contra uma baseline (previsão pela classe majoritária). Extração da importância de cada variável no modelo, identificando os 4 principais fatores de risco de crédito.

---

### 📉 Análise Preditiva de Cancelamento de Clientes (Churn)
`Python` `Pandas` `Plotly`

Análise exploratória completa de uma base de clientes, com limpeza de dados, tratamento de valores nulos e segmentação por variáveis contratuais e comportamentais. Identificação dos 3 principais fatores associados a 100% de cancelamento em determinados grupos (tipo de contrato, volume de contato com call center e atraso de pagamento), com recomendações objetivas de retenção. Achados apresentados por meio de dashboards interativos em Plotly, simulando o impacto de ações corretivas na taxa de cancelamento.

---

### ⚙️ Robô de Automação (RPA) para Cadastro em Massa de Produtos
`Python` `PyAutoGUI` `Pandas`

Automação de um processo manual e repetitivo de cadastro de produtos em sistema web, eliminando a digitação individual de cada item. Integração de leitura de planilhas com Pandas à simulação de interação humana (login, preenchimento de formulários e navegação) via PyAutoGUI, reduzindo drasticamente o tempo operacional da tarefa.
